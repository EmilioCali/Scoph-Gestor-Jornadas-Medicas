# Glosario

Términos que aparecen en API, UI y tickets. Úsalos en español de
dominio; no los “traduzcas” a nombres nuevos en inglés en las rutas.

| Término | Significado en SCOPH |
| --- | --- |
| Jornada | Evento médico de campo (`Workday`). No es “un día laboral de RR.HH.”. |
| Inventario central | Stock en bodega, no asignado a una jornada. |
| Inventario de jornada | Stock transferido a una jornada concreta. |
| Lote | Partida de un medicamento con vencimiento y cantidades. |
| Movimiento | Documento de ENTRADA, SALIDA o TRANSFERENCIA. |
| Receta | Subtipo de salida asociado a dispensación. |
| Retorno | Devolución de stock de jornada a central. |
| Categoría | Clasificación del medicamento (puede haber más de una). |
| Unidad de medida | Cómo se expresa la concentración / conteo. |
| Unidad de empaque | Caja, blíster, unidad, etc. |
| Auditoría | Registro de acción + módulo + usuario en core-service. |
| MEDICO | Rol de usuario de campo, no un título profesional validado por el sistema. |
| Ticket / TKT | Unidad de trabajo del ciclo formativo (rama + PR). |

Roles técnicos: ver [ROLES-Y-PERMISOS.md](./ROLES-Y-PERMISOS.md).
